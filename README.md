# 데일리 업무 스케줄러

오늘 할 업무를 입력하고 버튼 한 번만 누르면, **우선순위 순서와 이유, 30분 단위 하루 시간표**를 10초 안에 만들어 주는 웹 앱입니다.
못 한 업무는 다음 날로 이어 주고, 한 주 동안 이행한 업무는 주간 리포트로 모아 보여 줍니다.

> 배포 주소: DEPLOY_URL_PLACEHOLDER

## 왜 만들었나

직원들은 매일 아침 보고서·결재·회의 준비·민원 응대 등 여러 업무 앞에서 "무엇부터 할지"를 스스로 판단합니다. 순서를 정하는 데 시간이 들고, 급하지 않은 일에 먼저 손이 가 마감을 놓치기도 합니다. 이 앱은 중요도·마감 기한·업무 성격을 같은 기준으로 따져 하루 계획을 대신 짜 줍니다. (기획 배경은 [PRD.md](PRD.md))

## 주요 기능

- **업무 입력**: 업무명·중요도·마감 기한·예상 소요 시간·업무 유형·시작 시각 지정을 한 줄씩, 최대 15개
- **우선순위 정렬**: 마감 4시간 이내 우선, 기한 지난 업무 맨 앞, 그 외 중요도 순. 순서는 규칙대로 **코드가 정하고**, AI는 업무마다 30자 이내 이유 문구만 씁니다.
- **하루 시간표**: 30분 단위, 점심시간(12:00~13:00) 제외, 집중 업무는 오전·단순/협업 업무는 오후, 마감과 시작 시각 지정을 먼저 지킴. 못 넣은 업무는 "오늘 처리 불가"로 표시
- **이행 체크 · 시간표 복사 · 근무 시간 변경**
- **미완료 업무 이월**: 못 한 업무를 이름 또는 사번 + PIN별로 보관했다가 다음 날 불러옵니다.
- **주간 이행 업무 리포트**: 이행한 업무를 월~일 일자별로 보여 줍니다.

## 이렇게 씁니다

1. 이름 또는 사번과 PIN(6자 이상)을 입력합니다. (내 저장 기록을 다른 사람이 보지 못하게 하는 용도입니다.)
2. 오늘 할 업무를 입력하고 **[시간표 만들기]**를 누릅니다.
3. 우선순위와 시간표가 나오면, 한 일은 체크합니다. 못 한 일은 다음 날 **[이월 업무 확인] → [가져오기]**로 이어서 처리합니다.
4. 화면 맨 아래 **[주간 이행 업무 리포트 확인하기]**에서 한 주의 이행 업무를 확인합니다.

## 기술 스택

| 구분 | 사용한 것 |
|---|---|
| 화면·서버 | Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4 |
| AI | OpenAI API (우선순위 이유 문구 작성만) |
| 저장 | Supabase (Postgres) — 이월 보관함·이행 기록만, 서버에서만 접근 |
| 입력 검사 | zod |
| 배포 | Vercel |

## 폴더 구조

```
app/        화면(입력·결과·주간 리포트)과 서버 API (api/schedule, api/carryover, api/report)
lib/        정렬·시간표·검사 규칙, 보안 보호 코드, 날짜 계산
supabase/   저장소 표 만들기 SQL
tests/      API·규칙 시험(api.test.mjs), 성공 기준 측정(measure.mjs)
scripts/    기존 기록을 PIN 키로 옮기는 한 번용 도구
```

## 로컬에서 실행하기

```bash
npm install
cp .env.example .env   # 아래 환경 변수 값을 채웁니다
npm run dev            # http://localhost:3000
```

| 환경 변수 | 용도 |
|---|---|
| `OPENAI_API_KEY` | 우선순위 이유 문구 작성 (없으면 코드가 만든 기본 문구를 씀) |
| `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` | 이월·주간 리포트 저장소 (없으면 두 기능만 꺼지고 시간표는 그대로 동작) |
| `OWNER_HASH_SECRET` | 이름·사번·PIN을 변환(해시)하는 비밀 키 (임의의 긴 문자열) |
| `OPENAI_MODEL` | (선택) 기본값 `gpt-4.1-mini` |

저장소를 쓰려면 Supabase SQL Editor에서 `supabase/carryover.sql`, `supabase/done.sql`을 한 번씩 실행합니다.
키 값은 **절대 저장소에 올리지 않습니다**(`.env*`는 `.gitignore`로 제외). 변수 이름 앞에 `NEXT_PUBLIC_`을 붙이지 않아 브라우저로 노출되지 않습니다.

## 보안·개인정보 안내

- **대외비·비밀 내용, 고객·직원의 실명·전화번호·주민등록번호는 입력하지 마세요.**
- 입력한 업무명은 우선순위 이유 문구를 쓰기 위해 AI 서비스(OpenAI, 미국)로 전송됩니다.
- 이월·주간 리포트용으로 이름·사번·PIN을 변환한 값(원문은 저장하지 않음)으로 업무가 서버에 저장되며, 이월 업무는 30일, 이행 기록은 90일 뒤 자동 삭제됩니다. 화면의 **[내 저장 기록 모두 삭제]**로 언제든 지울 수 있습니다.
- 서버 API는 같은 사이트에서 온 JSON 요청만 받고, 사용자별 요청 횟수를 제한합니다.
